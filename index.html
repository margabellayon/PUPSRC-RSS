Project Rationale

The PUP Santa Rosa Room Reservation System is designed to make room booking easier and more organized for students and administrators. The maroon and gold color scheme represents PUP and helps connect the website to the school's identity.

A simple layout with clear labels, buttons, and room cards allows users to navigate the system without confusion. The room search and floor filters make it easier to find available rooms, while the booking page allows students to check their reservation status. Different colors are used for pending and approved requests so users can recognize each status quickly. The admin dashboard helps administrators manage and review reservation requests.

The responsive design allows the website to be viewed on both phones and computers. Overall, the design focuses on creating a clean, accessible, and convenient experience while maintaining a consistent appearance that reflects PUP's identity and supports the everyday needs of its users.
